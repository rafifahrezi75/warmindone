**APLIKASI WARMINDONE**

Warmindone merupakan aplikasi mobile berbasis Android yang dibangun untuk membantu proses pemesanan makanan dan minuman pada warmindo atau UMKM kuliner secara digital. Aplikasi ini dirancang untuk memberikan pengalaman pemesanan yang lebih praktis, cepat, dan modern bagi pelanggan, sekaligus membantu pengelolaan menu dan transaksi pada usaha kuliner atau warmindo.

Aplikasi ini memiliki tampilan antarmuka yang sederhana dan mudah digunakan sehingga pengguna dapat melakukan pemesanan makanan secara langsung melalui smartphone tanpa harus melakukan pencatatan manual. Selain itu, aplikasi juga mendukung proses autentikasi pengguna dan pengelolaan data menu agar sistem lebih terorganisir.

### **Fitur-Fitur Aplikasi**

- **Splash Screen & Welcome Screen**  
  Menampilkan halaman pembuka aplikasi sebagai identitas aplikasi sebelum pengguna masuk ke halaman utama.  
- **Login dan Register**  
  Pengguna dapat membuat akun baru serta melakukan login untuk mengakses fitur aplikasi secara aman.  
- **Home Menu**  
  Menampilkan daftar menu makanan dan minuman yang tersedia pada warmindo lengkap dengan tampilan yang menarik.  
- **Detail Menu**  
  Pengguna dapat melihat informasi detail terkait menu yang dipilih, seperti nama makanan, harga, dan deskripsi.  
- **Keranjang (Cart)**  
  Memungkinkan pengguna menyimpan pesanan sebelum melakukan checkout.  
- **Pemesanan Makanan**  
  Pengguna dapat melakukan proses pemesanan makanan dan minuman secara langsung melalui aplikasi.  
- **Riwayat Pesanan**  
  Menyimpan data transaksi atau pesanan yang pernah dilakukan oleh pengguna.  
- **UI/UX Modern**  
  Menggunakan desain antarmuka yang sederhana, modern, dan responsif agar nyaman digunakan oleh pengguna.

### **Tech Stack**

Aplikasi Warmindone dikembangkan menggunakan beberapa teknologi berikut:

- **Programming Language:** Java  
- **Platform:** Android Studio  
- **Database:** Firebase Firestore  
- **UI Design:** XML Layout Android  
- **Architecture:** Activity & Intent Based Navigation  
- **Version Control:** Git & GitHub  
- **Authentication:** Firebase Authentication  
- **Backend Support:** Firebase Services

### **Tujuan Pengembangan**

Warmindone dibuat sebagai solusi digitalisasi layanan pemesanan pada usaha warmindo atau UMKM kuliner agar proses pelayanan menjadi lebih efektif, efisien, dan terintegrasi. Selain itu, aplikasi ini juga dapat menjadi media pembelajaran pengembangan aplikasi mobile Android menggunakan Java dan Firebase.
